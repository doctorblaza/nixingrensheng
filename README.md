# 逆行人生

外卖骑手第一人称 3D 送餐游戏。骑电瓶车穿梭在城市的街道与弄堂之间，限时把外卖送到客户家门口。

🎮 **在线试玩**：https://doctorblaza.github.io/nixingrensheng/

## 玩法

- 第一人称驾驶：视野里有车把、刹车、仪表盘，手机架在车把支架上做导航（不是悬浮 HUD）
- 每单两段式：先去商家门口取餐（店门口停稳 2 秒），再送到客户家门口，然后自动派下一单
- 12 条真实路名，街道之间穿梭，换街时有蓝色路名牌
- 人行道可以骑：有限速、轻微颠簸，行人会避让
- 严重碰撞直接 game over：撞墙、撞上逆行的车/电瓶车
- 手机竖屏会提示横过来，横屏才能玩

## 内容

- 300 个手工 Three.js 建模：车辆 48 / 人物 52 / 建筑 54 / 街景 52 / 设施 40 / 生活物件 54，边角全部圆润化
- 8 家取餐商家：一点点、沪上阿姨、老盛昌、大壶春、吉祥馄饨、永和豆浆、沙县小吃、兰州拉面

## 操作

- ← / → 或 A / D：左右转向（不按只走直线，不会自动转弯）
- ↑ / W：加速，↓ / S：刹车
- 手机端：横屏后用屏幕两侧按钮控制
